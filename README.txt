今日はなに食べた？ - PWA試作版 v0.6

■ v0.6 仕様変更
- カレンダー画面と「その日の写真ページ」を完全に分離
- カレンダー下に、その日の写真詳細を表示しない
- カレンダーでは朝 / 昼 / 夜 / 間の選択中カテゴリだけサムネイル表示
- 写真のある日またはサムネイルをタップすると別画面の写真ページへ移動
- 写真ページでは960×720の保存画像を大きく表示
- 写真の直下に保存済みメモをキャプションとして表示
- 同じ写真ページ内でメモを入力・保存可能（200文字まで）
- 写真ページ左上の「戻る」で、直前のカレンダーへ戻る
- 写真の撮り直し / 削除も写真ページから操作
- 撮り直してもメモは保持
- 撮影後はアプリ内プレビューを挟まず「○食として記録しますか？」だけ確認
- Service Workerをv7へ更新

■ 基本UIフロー
1. 起動 → 朝食 / 昼食 / 夜食 / 間食 の撮影ボタン
2. 撮影 → 「記録しますか？」 → OKで保存
3. 記録済みの食事ボタンはグレー表示で押せない
4. 「カレンダーを見る」 → 朝 / 昼 / 夜 / 間を切替
5. カレンダーのサムネイル → 別画面の写真ページ
6. 写真ページ → 拡大写真 + キャプション + メモ編集
7. 左上「戻る」 → 同じ月・同じ食事カテゴリのカレンダーへ戻る

■ 画像仕様
- 保存画像：960×720px / WebP / 品質68%
- サムネイル：240×180px / WebP
- 保存先：ブラウザのIndexedDB（端末内）

■ 保存期間
- 当月＋前月の2か月だけ保持
- 保存期間を超えた写真・サムネイル・記録・メモは自動削除
- バックアップ機能なし

■ PWA
- HTTPS配信時にホーム画面へ追加可能
- Service Workerキャッシュ v7
- file:// での動作はブラウザ差があるため、最終確認はHTTPS配信を推奨
