# 今日はなに食べた？

食事の写真とメモを端末内に記録するPWAです。ビルド不要の静的サイトです。

## 使い方

1. 朝食・昼食・夕食・間食を選び、写真を撮影して記録します。
2. カレンダーのデフォルトは「全食」です。各日のマス内で朝・昼・夕・間を縦4段の色分けで表示し、記録済みの食事だけマークを表示します。
3. 朝食・昼食・夕食・間食の各ボタンに切り替えると、その食事のサムネイルだけを表示します。
4. 記録済みマークまたはサムネイルをタップすると別画面で拡大表示され、200文字までのメモを保存できます。
5. ブラウザーの「ホーム画面に追加」からアプリとして利用できます。

## 保存について

写真とメモはブラウザーのIndexedDBに保存します。当月と前月の2か月分のみ保持し、それ以前の記録は自動削除します。バックアップ機能はありません。端末やブラウザーを変更してもデータは同期されません。

保存画像は960×720のWebP（品質68%）、サムネイルは240×180のWebPです。

旧データで meal が「夜」「夜食」「夕」「夕食」になっている場合は、内部の `dinner` に正規化して夕食として扱います。
