# 今日何食べた？

食事の写真とメモを端末内に記録するPWAです。ビルド不要の静的サイトです。

## 使い方

1. 朝食・昼食・夕食・間食を選び、写真を撮影して記録します。
2. カレンダーで食事カテゴリを切り替えて写真を振り返ります。
3. 写真をタップすると別画面で拡大表示され、200文字までのメモを保存できます。
4. ブラウザーの「ホーム画面に追加」からアプリとして利用できます。

## 保存について

写真とメモはブラウザーのIndexedDBに保存します。当月と前月の2か月分のみ保持し、それ以前の記録は自動削除します。バックアップ機能はありません。端末やブラウザーを変更してもデータは同期されません。

## 配置

GitHub Pagesでmainブランチのルートを公開します。index.html、manifest.webmanifest、sw.js、icon-192.png、icon-512.pngを同じ階層に置いてください。HTTPSで配信するとService Workerによるオフライン利用に対応します。
