# 今日なに食べた？

食事の写真とメモを端末内に記録する、ビルド不要のPWAです。

- 公開URL: https://jike-gml.github.io/kyou-nani-tabeta/
- バージョン: v0.9（保存期間3か月対応）
- 保存画像: 960×720px / WebP
- サムネイル: 240×180px / WebP
- 保存期間: 当月＋過去2か月の計3か月

## 2026-10-17 テーマ切り替え

- トップ画面のヘッダーをタップすると「現行 → カラフルPOP → クール」の順に切替
- テーマは localStorage に保存し、再起動時も継続
- TOP・カレンダー・お気に入り・記録詳細に共通適用
- テーマスタイルは themes.css に分離し、既存の保存記録には触れない

## 2026-10-17 仕様更新

- 記録保存期間を「当月＋過去2か月の計3か月」に延長
- カレンダーの閲覧期間・保存期限に連動する処理を更新
- Androidのナビゲーションバーを白背景・黒アイコンに寄せるためPWAのテーマ色とライトモードを指定（端末・ブラウザ依存で完全固定は保証できません）
- Service Workerキャッシュを v42 に更新

## 保存について

写真とメモはブラウザーのIndexedDBに保存されます。端末やブラウザーを変更しても同期されません。ホーム画面のアプリ削除やサイトデータ削除を行うと、保存済みデータが失われる場合があります。

## 配置

GitHub Pagesで `main` ブランチのルートを公開します。`index.html`、`manifest.webmanifest`、`sw.js`、`icon-192.png`、`icon-512.png` を同じ階層に置いてください。
